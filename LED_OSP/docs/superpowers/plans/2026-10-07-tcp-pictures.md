# TCP 图片存储与显示实现计划

**目标：** 电脑将图片转换为 800×480 黑白数据，经现有 TCP 客户端保存到 W25Q128，校验后显示。

**结构：** Application/Picture 负责固定槽存储；download_stream 分辨 FWUP/PIC1 包；
现有固件 TCP 接收队列复用，屏幕任务只通过编号接收显示请求。屏幕控制驱动保持原版。

**技术：** STM32 SPL、FreeRTOS、LwESP、W25Q128、Python/Pillow。

- [x] 存储：图片区 0x300000～0xFFFFFF，256 槽，每槽 0xD000 字节；
  前 4KiB 管理信息，后 48KiB 正文。正文固定 48000 字节，1 白、0 黑，MSB 优先。
  先擦除并验证管理扇区，正文写完并读回 CRC 后才提交有效标记；中途掉线不能产生有效新图。
  图片覆盖失败可能丢失该槽旧图，其他图片和固件区不得受影响。
- [x] 协议：32 字节小端 PIC1/version/slot/width/height/length/crc/reserved；
  READY 后按 256 字节分批发送，累计 ACK，存储成功 DONE。
  图片完成后允许下一包；固件仍只接收一次，维持原 A/B 状态保护。
  固件基线未就绪时禁止 FWUP，但外部 Flash 可用时允许 PIC1。
- [x] 屏幕：持久任务、单项显示队列及静态 48000 字节缓冲，不能从 32KiB 堆申请整屏。
  启动默认读 0 号图，无图时保留原测试；全部屏幕操作由该任务串行执行。
  DONE 只代表保存成功，显示结果单独记录日志；忙时队列保留最后一次请求。
- [x] 工具：支持 PNG/JPG/BMP 和 48000 字节 BIN；等比例缩放、白边、透明白底、黑白转换。
  输出 BIN/预览，单连接可传多图。默认首槽 0、端口 8080。
- [x] 验证：NOR 模型检查范围、CRC、覆盖、部分写入、擦除失败；
  字节流测试拆包/合包及固件路径，屏幕任务测试重复显示与失败，Python 工具测试像素布局及停等协议。
  执行现有回归、Keil 全量编译、检查 RAM 预算、生成含校验字的 App/合并 HEX。

与用户确认：使用 TCP 传图；屏幕 PWR 已改 PF7。硬件显示最终需上板验证。

验证结果：主机回归全部通过；Keil ARMCC5 编译 0 错误、0 警告；RW+ZI=100624 字节，包含 32KiB RTOS 堆；App/合并 HEX 已更新并通过地址、向量和校验字检查。没有自动烧录，板上实际显示待验证。
