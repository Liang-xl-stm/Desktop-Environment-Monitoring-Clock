# 主机回归测试

在工程根目录执行 `python Tests/run_tests.py`。

需本机有 GCC；优先使用 CC 环境变量或系统 gcc，随后查找当前电脑的 MinGW。
结果输出到 OBJ/host_tests，这些可执行文件不能烧录开发板。

覆盖 W25Q128 页内回卷、跨页和大数据读写、地址边界、忙超时、锁拒绝和传输错误；
墨水屏 GPIO 与 PF6 隔离、SPI 字节时序、整屏/局部数据长度、BUSY 超时、RTOS 延时及任务失败处理；
256 个图片槽范围保护、断点写入/提交、正文 CRC、图片拆包合包、连续多图 TCP 及固件拒绝条件；
图片工具像素布局、透明底色、等比例缩放、原始 BIN、分段 ACK 和多图输出文件名；
固件启动保护、管理扇区恢复、TCP 拆包合包、A/B 状态和 CRC；
日志格式、过滤、二进制原样输出、互斥及 ISR 拒绝；
网络任务未启动时 LED 和控制台独立运行；电脑发送工具分段 ACK 与最终确认。

正常结果以 PASS all host regression suites 结束。
主机测试不替代实际 GPIO、电气时序、板上抢占和任务栈观察。
